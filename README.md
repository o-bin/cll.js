# cll.js is a graph-based 3D graphic library for your browser

This is still a  project under development. I hope you can contribute with me.

Try this library cloning this project and then type:

```
npm install

npm run dev
```

and that's it! if you want to change the preview, just go to /src/scenes/main_scenes.js

and then comment one of these lines!
```
// export const ActiveScene = PencilDimensional;
// export const ActiveScene = PencilScene;
 export const ActiveScene = ColorfulCubeScene;
// export const ActiveScene = CubeScene;
// export const ActiveScene = TriangleScene;
```
